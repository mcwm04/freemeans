# freemeans: local agent

The Freemeans local agent: a free-aware, policy-checked, OpenAI-compatible router for **your own** free AI quotas. Keys stay on your machine.

```bash
pip install -e ".[dev]"
cp freemeans.example.yaml freemeans.yaml
freemeans explain --project client-work
freemeans serve        # http://127.0.0.1:4000/v1
```

See the repository README for the full guide.
